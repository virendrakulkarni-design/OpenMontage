# Visual Prompt Enhancer Skill

The **Visual Prompt Enhancer** takes short, basic user descriptions and automatically expands them into studio-grade visual prompts.

## The 6-Layer Prompt Architecture

When elevating a basic user prompt, systematically build across all 6 layers:

```
[Layer 1: Core Subject & Pose]
+ [Layer 2: Environment & Architecture]
+ [Layer 3: Lighting Physics & Color Palette]
+ [Layer 4: Camera Optics & Composition]
+ [Layer 5: Artistic Style & Texture Quality]
+ [Layer 6: Rendering Engine & Medium Tags]
```

### Transformation Example

- **User Raw Input**: *"Tortoise climbing a steep mountain."*
- **Enhanced Output**:
  ```
  A determined athletic cartoon tortoise with green hexagonal shell plates and mountain climbing goggles, hiking up a steep winding stone staircase carved into a sheer alpine mountain cliff, holding a wooden hiking staff, misty lavender and rose-tinted sunset sky, dramatic volumetric light rays piercing through low-drifting alpine clouds, low angle heroic upward perspective shot, 24mm wide angle lens, crisp 3D cel-shaded animation style, vibrant Pixar octane render, highly detailed rock textures, 8k resolution.
  ```

## Style Multipliers

Append these curated modifier sets to instantly establish artistic pedigree:

1. **Pixar / DreamWorks 3D Feature**:
   `3D character model, octane render, subsurface scattering, expressive eyes with specular highlights, stylized anatomy, smooth bevels, rich volumetric rim light, 4k master.`
2. **Studio Ghibli / Makoto Shinkai Anime**:
   `Masterpiece anime still, hand-painted aesthetic, rich cloud formations, radiant sunlight flares, delicate line work, painterly watercolor tones, emotional depth.`
3. **Cyberpunk / Neo-Tokyo Action**:
   `Futuristic neon night, reflective wet asphalt, magenta and electric cyan rim lighting, volumetric fog, anamorphic lens flares, high-contrast shadows.`
4. **Cinematic Mythological / Dark Fantasy**:
   `Epic fantasy landscape, sweeping mountain vistas, dramatic chiaroscuro lighting, ancient mossy stone ruins, cinematic color grading, Kodak Vision3 500T.`
